# SEO Hierarchy

### От поисковых запросов к структуре интернет-магазина

Магистерский проект о том, как с помощью языковой модели построить понятное дерево товарных категорий и сократить ручную работу SEO-специалиста.

**Сейчас:** постановка исследования и план экспериментов. **Следующий этап:** реализация прототипа и сравнение методов.

## Какую задачу решаем

Люди ищут один товар разными словами: «купить розы», «розы купить», «красные розы». Специалисту нужно решить, какие запросы объединить на одной странице, для каких создать отдельную категорию и как связать эти категории между собой.

Проект исследует способ автоматизировать эти решения и передавать неоднозначные случаи человеку на проверку.

## Пример результата

Искусственный пример показывает предполагаемую логику. Реальные назначения будут проверяться экспериментально.

| Что ищет пользователь | Предлагаемое решение |
|---|---|
| Купить розы; розы купить | Одна категория «Розы» |
| Красные розы | Подкатегория «Красные розы» |
| Букет на день рождения | Категория по поводу покупки |
| Как ухаживать за розами | Информационный запрос вне товарного дерева |

```text
Цветы                         Букеты по поводу
└── Розы                      └── На день рождения
    └── Красные розы
```

Спрос считается по уникальным запросам: пересечения веток и суммы родителей и детей не должны увеличивать общий охват.

## Что исследуем

**Вопрос:** помогают ли проверки структуры и обработка неоднозначности получать более качественное дерево с меньшим объёмом экспертных исправлений?

Сравним три подхода:

1. Кластеризация запросов с заданной процедурой построения дерева.
2. Языковая модель без дополнительного этапа проверок.
3. Языковая модель с ограничениями структуры и выделением спорных случаев.

Оценим правильность назначений, логичность вложенности, охват спроса, дубли, время доработки и стоимость обработки. Планируется проверка на двух предметных областях.
