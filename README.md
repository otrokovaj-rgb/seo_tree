# Построение иерархии товарных категорий по поисковому спросу

Материалы магистерского исследования о построении структуры категорий интернет-магазина с помощью больших языковых моделей. На входе — поисковые запросы и измеренный спрос. На выходе — предложенная иерархия, назначения запросов и спорные случаи для экспертной проверки.

## Тема диссертации

Разработка и оценка метода построения иерархии товарных категорий по поисковому спросу с использованием больших языковых моделей и структурных ограничений.

Тема и план предложены для обсуждения с научным руководителем. Окончательное согласование ещё не зафиксировано.

## Практическая задача

Специалист должен определить, какие категории нужны сайту, какие запросы относятся к одной странице и как связать категории. Ошибки приводят к дублированию тем, пропущенному спросу и большому объёму ручных исправлений. Исследование проверит, можно ли сократить эту работу при сохранении качества.

## Пример

Запросы «купить розы» и «розы купить» могут относиться к категории «Розы», «красные розы» — к её подкатегории. «Как ухаживать за розами» требует отдельного решения как информационный запрос. Это иллюстрация; реальные назначения должны проверяться по правилам предметной области.

Категории по видам товаров и по поводу покупки могут пересекаться. Для подсчёта охвата используются уникальные исходные ключи запросов: складывать спрос всех родителей и детей нельзя.
