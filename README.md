# Демонстрационные данные


queries.csv содержит query_id и query. expected-output.json показывает возможные категории, типы связей и назначения. Это предложенный пример.

Информационный запрос остаётся вне товарного дерева. Категория по поводу покупки хранится отдельно от ветки по виду товара.

Для реального набора опишу источник, период, регион, единицу спроса, пороги отбора, исходные ключи, процедуру разметки и условия использования.
