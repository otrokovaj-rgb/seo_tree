# Демонстрационные данные

Все примеры в этой папке искусственные.

queries.csv содержит query_id и query. expected-output.json показывает возможные категории, типы связей и назначения

Информационный запрос остаётся вне товарного дерева. Категория по поводу покупки хранится отдельно от ветки по виду товара;

Для реального набора потребуется описать источник, период, регион, единицу спроса, пороги отбора, исходные ключи, процедуру разметки и условия использования. Значения спроса в демонстрацию намеренно не добавлены, чтобы искусственные числа нельзя было принять за наблюдения.
