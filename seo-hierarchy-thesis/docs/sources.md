# Публичные источники

Источники использованы в обзоре от 1 октября 2026 года. Тексты не копируются целиком. Наличие ссылки не означает воспроизведение или независимую проверку заявленных функций.

1. [Топвизор — методы кластеризации](https://topvisor.com/ru/support/clustering/method/). Группировка по выдаче.
2. [JustMagic — кластеризация с распределением](https://just-magic.org/doc/mark_onl.php). Назначение вокруг запросов-маркеров.
3. [Ahrefs Keywords Explorer](https://ahrefs.com/keywords-explorer). Группировка по Parent Topic и словам.
4. [Semrush Keyword Strategy Builder](https://www.semrush.com/kb/1058-keyword-strategy-builder). Темы, основные страницы и подстраницы.
5. [Keyword Insights — описание кластеризации](https://www.keywordinsights.ai/blog/keyword-clustering-guide/). Группировка по выдаче и смыслу, тематические кластеры и ограничения.
6. [MarketMuse — Topic Cluster Building](https://help.marketmuse.com/support/solutions/articles/80001167731-topic-cluster-building). Планирование тематического контента.
7. [Google Search Central — структура интернет-магазина](https://developers.google.com/search/docs/specialty/ecommerce/help-google-understand-your-ecommerce-site-structure). Навигационные связи и обнаружение страниц.
8. [TaxoAlign — EMNLP 2025](https://aclanthology.org/2025.emnlp-main.1536/). Генерация таксономий научных публикаций.
9. [Context-Aware Hierarchical Taxonomy Generation for Scientific Papers via LLM-Guided Multi-Aspect Clustering](https://arxiv.org/abs/2509.19125). Связанное исследование генерации иерархий.

Научные работы — исходные точки для полного литературного обзора. Систематический поиск, анализ методик и воспроизведение их результатов ещё не выполнены.

Внутренние источники изучались ранее как контекст существующего подхода. Их содержимое и адреса не включены в этот подготовленный пакет; текущая удалённая версия корпоративного проекта не проверялась.
