# Обзор рынка и актуальность исследования

Обзор составлен 1 октября 2026 года по публичной документации и сохранён 2 октября. Это обзор функций, а не практический сравнительный тест. Цены, доли рынка и доступность оплаты не исследовались. Функции сервисов могут изменяться.

## Существующие решения

| Решение | Возможности по документации | Значение для исследования |
|---|---|---|
| Топвизор | Группировка по общим URL в выдаче, методы soft и hard | Базовый подход группировки под страницы. [Источник](https://topvisor.com/ru/support/clustering/method/) |
| JustMagic | Кластеризация по выдаче, распределение вокруг заданных маркеров | Сравнение с управляемым экспертом назначением. [Источник](https://just-magic.org/doc/mark_onl.php) |
| Ahrefs | Группировка по Parent Topic и связанным словам | Автоматическое выделение общих тем уже существует. [Источник](https://ahrefs.com/keywords-explorer) |
| Semrush Keyword Strategy Builder | Темы, основные страницы и подстраницы, иерархический вид | Прямой аналог части задачи структурирования страниц. [Источник](https://www.semrush.com/kb/1058-keyword-strategy-builder) |
| Keyword Insights | Группировка по выдаче, тематические кластеры, анализ интента | Аналог сочетания группировки и тематического планирования. [Источник](https://www.keywordinsights.ai/blog/keyword-clustering-guide/) |
| MarketMuse | Анализ тематических кластеров, рекомендации по созданию и обновлению контента | Смежный подход к тематическому покрытию. [Источник](https://help.marketmuse.com/support/solutions/articles/80001167731-topic-cluster-building) |

## Основания актуальности

Google объясняет, что навигационные связи помогают обнаруживать страницы и понимать структуру интернет-магазина. Это подтверждает практическое значение структуры, но не доказывает эффект предлагаемого метода на позиции. [Документация Google](https://developers.google.com/search/docs/specialty/ecommerce/help-google-understand-your-ecommerce-site-structure).

Keyword Insights описывает различие смысловой группировки и группировки по выдаче, включая риск объединения разных интентов и чрезмерного дробления кластеров. Эти ограничения мотивируют проверку сочетания сигналов. [Описание методов](https://www.keywordinsights.ai/blog/keyword-clustering-guide/).

Генерация таксономий с помощью языковых моделей уже является научным направлением. TaxoAlign и работа об LLM-guided multi-aspect clustering исследуют иерархии научных публикаций. Они дают направления для обзора литературы; их результаты нельзя автоматически переносить на товарные запросы. [TaxoAlign](https://aclanthology.org/2025.emnlp-main.1536/), [исследование кластеризации](https://arxiv.org/abs/2509.19125).

## Предлагаемая область исследования

Гипотеза проекта — явные ограничения и обработка неопределённости могут улучшить пригодность иерархии для товарного сайта. Проверяемые аспекты: правильность связей, отсутствие дублей, охват спроса при заданной точности, время экспертной доработки.

Публичная документация не позволяет установить отсутствие этих возможностей у всех конкурентов или превосходство предлагаемого метода. Подтвердить преимущества должен эксперимент.
