# Протокол оценки качества

Это предложенный план эксперимента

## Сравниваемые подходы

| Вариант | Назначение |
|---|---|
| A | Кластеризация запросов и простая воспроизводимая процедура построения дерева |
| B | Языковая модель без отдельного этапа ограничений и обработки неопределённости |
| C | Предлагаемый метод с ограничениями и очередью спорных случаев |


## Данные и эксперты

Выделить разработочную и независимую тестовую части. На тестовой части не настраивать правила. Разделять близкие запросы по смысловым группам, чтобы перефразировки не оказались одновременно в обучающей и тестовой частях. При настройке на одной области проверить перенос на другую.

Разметка включает допустимые назначения, оценку связей и спорные случаи. Допускаются несколько корректных иерархий. Экспертам не показывать название метода; порядок результатов перемешать. По возможности привлечь двух экспертов, измерить согласие и согласовать разногласия. AI-ревью не заменяет независимую экспертную оценку.

## Метрики

- Точность назначения: доля корректных назначений среди проверенных назначений. Для нескольких назначений считать пары запрос–категория и отдельно качество на уровне запроса.
- Корректность связей: доля принятых экспертами связей среди проверенных связей.
- Текстовый охват: число уникальных назначенных запросов / число запросов в зафиксированной выборке.
- Охват спроса: сумма выбранного сигнала по уникальным корректно назначенным ключам / сумма того же сигнала на релевантной выборке. Полная оценка требует разметки или обоснованного выборочного оценивания.
- Дубли: доля категорий, признанных экспертами смысловыми дублями.
- Ручная доработка: время и число исправлений до принятия результата по единым критериям.
- Стоимость: затраты на модели и обработку при одинаковом объёме входа.
- Устойчивость: изменение назначений и связей между повторными запусками.

Для каждой метрики фиксировать единицу, знаменатель, область, период и охват проверки. Покрытие назначениями не равно качеству: принудительное назначение всех запросов может дать высокий охват при большом числе ошибок.

## Проверка вклада механизмов

Сравнить полный метод с вариантами без структурных проверок, без обработки неопределённости и, при использовании, без структуры конкурента. Менять один механизм за раз; учитывать одинаковые бюджеты и версии моделей.

## Представление результатов

Показать результаты отдельно по областям и частотным группам, примеры ошибок и неопределённости. Использовать повторные запуски и доверительные интервалы. Для связанного корпуса выбирать единицу статистического пересэмплирования, учитывающую зависимости, например смысловые группы. Не выдавать результаты специально выбранных примеров за точность всего корпуса.

Числовые критерии успешности задаются до итогового эксперимента. Положительный результат не предполагается заранее; отрицательный результат тоже является исследовательским выводом.
